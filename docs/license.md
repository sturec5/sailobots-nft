# Art Blocks License Note

Art Blocks token metadata for this project lists the license as `NFT License`.

That is the project-level creative license label exposed by Art Blocks, not a standard code license for the repository itself.

## What I chose to do

- Keep the repository source mirror and provenance notes as-is.
- Record the Art Blocks license label here instead of adding a misleading root `LICENSE` file.
- Leave the repo free for you to add a separate code license later if you want one.

## Public references

- Project token metadata shows `license: "NFT License"`
- Art Blocks creator docs describe the project "Creative license" field as the place to enter a license such as NFT License 2.0 or a Creative Commons license
